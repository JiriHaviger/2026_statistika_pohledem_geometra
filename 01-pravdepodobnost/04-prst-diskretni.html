Poznámka

Pro vizuálně přívětivější zobrazení pravděpodobnostních funkci zde budeme využívat využít sloupcové grafy.

Příklad acylpyrin

U 80 % pacientů po podání Acylpyrinu nastane snížení teploty (úspěch, \(+\)), u 20 % stagnace nebo zvýšení teploty (neúspěch, \(-\)).

\(k\) Výsledek \(P(x_k)\)
1 \(+\) \(0,80\)
2 \(-\) \(0,20\)

Tohle je distribuce pro výsledek jednoho pokusu, co když jich ale máme více? Jaká je například pravděpodobnost, že ze tří pacientů budou dva úspěšně vyléčení (+)? Podívejme se na situaci u dvou, tří nebo obecně \(n\) pacientů (v našem případě nezáleží na pořadí, takže \((+, -) = (-, +)\)).

Počet pacientů Množina výsledků \(\Omega\)
1 \((+,-)\)
2 \((++, +-, --)\)
3 \((+++, ++-, +--, ---)\)
\(n\) \(\bigcup_{k=0..n} (\underbrace{+\dots +}_{k}, \underbrace{-\dots-}_{n-k})\)

Na pořadí pacientů nám nezáleží, ale mění se pravděpodobnosti. Například pro situaci tří pacientů, kdy jsou úspěšní všichni, existuje jediná možnost: \((+++)\). Pokud jsou ale úspěšní pouze dva, zahrnuje to tři možnosti: \((++-), (+-+), (-++)\).

Protože úspěšnost pacienta nezávisí na ostatních, mluvíme o nezávislých jevech a využijeme pravidla o součinu a součtu: \(P(+++) = P(+) \cdot P(+) \cdot P(+)\), ale pro dva úspěchy: \(P(\text{2 úspěchy}) = P(++-) + P(+-+) + P(-++) = 3 \cdot P(+)^2 \cdot P(-)^1\).

Konstantu \(3\) z předchozího výpočtu můžeme zobecnit pomocí binomického čísla jako počet možností, jak z \(n\) prvků vybrat \(k\) úspěchů, tedy \(\binom{n}{k}\), v našem případě \(\binom{3}{2} = 3\). Tato situace je typickým příkladem diskrétní distribucew, konkrétněji binomické distribuce.

4.1 Binomické rozdělní

Popisuje pravděodobnost několika úspěchů. Typickou otázkou je například: „Jaká je pravděpodobnost, že když hodíme šesti kostkami, tak padnou dvě šestky?“

PoznámkaBinomická distribuce (předpoklady)

Abychom mohli mluvit o binomickém rozdělení, musí být splněno:

  • Pokus končí buď úspěchem, nebo neúspěchem.
  • Pravděpodobnost úspěchu \(\pi\) je konstantní.
  • Pokusy jsou nezávislé.
  • Celkový počet pokusů je \(n\).
  • Počet požadovaných úspěchů je \(x\).

Obecný vzorec: \[p(x) = \binom{n}{x} \cdot \pi^x \cdot (1-\pi)^{n-x}\]

Kód 
import { Inputs } from "@observablehq/inputs"
viewof n = Inputs.range([1, 50], {step: 1, value: 10, label: "počet pokusů (n)"})
viewof p = Inputs.range([0, 1], {step: 0.01, value: 0.5, label: "prst úspěchu (π)"})

// 2. Efektivnější výpočet kombinačního čísla (aby prohlížeč nezamrzl)
function binom(n, k) {
  if (k < 0 || k > n) return 0;
  if (k === 0 || k === n) return 1;
  if (k > n / 2) k = n - k;
  let res = 1;
  for (let i = 1; i <= k; i++) {
    res = res * (n - i + 1) / i;
  }
  return res;
}

// 3. Výpočet pravděpodobnostní funkce (PMF)
function pmf(k, n, p) { 
  return binom(n, k) * Math.pow(p, k) * Math.pow(1 - p, n - k); 
}

// 4. Vykreslení grafu
Plot.plot({
  marks: [
    Plot.barY(
      Array.from({length: n + 1}, (_, k) => ({k, y: pmf(k, n, p)})),
      {x: "k", y: "y", fill: "steelblue"}
    ),
    Plot.ruleY([0])
  ],
  y: { grid: true, label: "P(X = k)" },
  x: { label: "k" }
})

Fuknce, kterou jsem takto zavedli se korektně označuje pravdpodobnostní funkce (probability mass function, pmf). Matematické podrobnosti o binomickém rozdělední viz Wikipedia contributors (2025).

Wikipedia contributors. (2025). Binomial distribution. https://en.wikipedia.org/wiki/Binomial_distribution

Binomické rozdělení patří do skupiny diskrétních pravděpodobnostních rozdělení. To znamená, že náhodná veličina v těchto případech nabývá pouze jasně oddělených, spočetných hodnot (typicky celých čísel \(0, 1, 2, \dots\)). 4.2 Geometrické rozdělení

Popisuje „čekání na první úspěch“. Typickou otázkou je například: „Jaká je pravděpodobnost, že budeme muset hodit kostkou právě pětkrát, než poprvé padne šestka?“ Viz podrobněji Shafer & Zhang (2012).

Shafer, D. H., & Zhang, Z. (2012). Introductory Statistics. Saylor Foundation. https://stats.libretexts.org/Bookshelves/Introductory_Statistics
PoznámkaGeometrická distribuce (předpoklady)
  • Pokusy jsou nezávislé.
  • Každý pokus má pouze dva výsledky (úspěch/neúspěch).
  • Pravděpodobnost úspěchu \(\pi\) je v každém pokusu stejná.
  • Ptáme se, po kolika pokusech \(x\) získáme první úspěšný

Obecný vzorec: \[p(x) = \pi \cdot (1-\pi)^{x}\]

Kód 
viewof p_geom = Inputs.range([0.01, 1], {step: 0.01, value: 0.2, label: "Prst úspěchu (π)"})

Plot.plot({
  height: 250,
  y: { grid: true, label: "P(X = k)" },
  x: { label: "Počet pokusů do 1. úspěchu (k)" },
  marks: [
    Plot.barY(Array.from({length: 20}, (_, i) => {
      const k = i + 1;
      return { k, y: Math.pow(1 - p_geom, k - 1) * p_geom };
    }), {x: "k", y: "y", fill: "steelblue"}),
    Plot.ruleY([0])
  ]
})

4.3 Hypergeometrické rozdělení

Podobá se binomickému, ale na rozdíl od něj modeluje výběry bez vracení. Použijeme ho například při výpočtu pravděpodobnosti, že mezi pěti vytaženými kartami z balíčku budou právě dvě esa (Grinstead & Snell, 2012).

Grinstead, C. M., & Snell, J. L. (2012). Introduction to Probability. American Mathematical Society. https://stats.libretexts.org/Bookshelves/Probability_Theory/Book%3A_Introductory_Probability_(Grinstead_and_Snell)
PoznámkaPředpoklady (Hypergeometrické)
  • Máme konečný soubor o velikosti \(N\).
  • V souboru je \(M\) objektů s danou vlastností (úspěchů).
  • Provedeme výběr \(n\) prvků bez vracení.

Obecný vzorec: \[P(x) = \frac{\binom{M}{x}\cdot \binom{N-M}{n-x}}{\binom{N}{n}}\]

Kód 
viewof N_hg = Inputs.range([10, 100], {step: 1, value: 50, label: "Velikost populace (N)"})
viewof M_hg = Inputs.range([1, N_hg], {step: 1, value: 10, label: "Počet úspěchů v populaci (M)"})
viewof n_hg = Inputs.range([1, N_hg], {step: 1, value: 10, label: "Velikost výběru (n)"})

// Pomocná funkce pro kombinační číslo
function combinations(n, k) {
  if (k < 0 || k > n) return 0;
  if (k === 0 || k === n) return 1;
  if (k > n / 2) k = n - k;
  let res = 1;
  for (let i = 1; i <= k; i++) res = res * (n - i + 1) / i;
  return res;
}

Plot.plot({
  height: 250,
  y: { grid: true, label: "P(X = k)" },
  x: { label: "Počet úspěchů ve výběru (k)" },
  marks: [
    Plot.barY(Array.from({length: Math.min(n_hg, M_hg) + 1}, (_, k) => ({
      k, 
      y: (combinations(M_hg, k) * combinations(N_hg - M_hg, n_hg - k)) / combinations(N_hg, n_hg)
    })), {x: "k", y: "y", fill: "steelblue"}),
    Plot.ruleY([0])
  ]
})

4.4 Poissonovo rozdělení

Vyjadřuje pravděpodobnost výskytu \(k\) událostí v určitém pevném intervalu (času, plochy atd.). Například počet pacientů přicházejících na pohotovost během jedné hodiny (Wikipedia contributors, 2024).

Wikipedia contributors. (2024). Poisson distribution. https://en.wikipedia.org/wiki/Poisson_distribution
PoznámkaPředpoklady (Poisson)
  • Události nastávají nezávisle na sobě.
  • Průměrná četnost výskytu (\(\lambda\)) je konstantní.
  • Dvě události nemohou nastat v přesně stejný okamžik.

Obecný vzorec: \[P(x) = \frac{\lambda^x \cdot e^{-\lambda}}{x!}\]

Kód 
viewof lambda = Inputs.range([0.1, 20], {step: 0.1, value: 3, label: "Průměrná četnost (λ)"})

// 2. Vlastní funkce faktoriálu (bezpečná)
function myFactorial(n) {
  let res = 1;
  for (let i = 2; i <= n; i++) res *= i;
  return res;
}

// 3. Výpočet dat
poissonData = d3.range(21).map(k => ({
  k: k,
  y: (Math.pow(lambda, k) * Math.exp(-lambda)) / myFactorial(k)
}))

// 4. Graf s osou typu "band"
Plot.plot({
  height: 250,
  y: { 
    grid: true, 
    label: "P(X = k)",
    domain: [0, 0.5] 
  },
  x: { 
    label: "Počet událostí (k)",
    type: "band" // TOTO vyřeší zobrazení sloupců
  },
  marks: [
    Plot.barY(poissonData, {
      x: "k", 
      y: "y", 
      fill: "steelblue",
      tip: true
    }),
    Plot.ruleY([0])
  ]
})

Těmito (a dalšími) rozděleními se v tomto textu nebudeme dále podrobně zabývat, ale je dobré o nich vědět.

Tip💡 Jak na to v Excelu?

Pokud potřebujete tyto pravděpodobnosti spočítat v tabulkovém procesoru, použijte následující funkce. Poslední hodnotu ve funkci nastavte na NE (nebo 0) pro pravděpodobnost přesné hodnoty, nebo na ANO (nebo 1) pro kumulativní pravděpodobnost.

  • Binomické: =BINOM.DIST(x; n; p; NE)
  • Hypergeometrické: =HYPGEOM.DIST(x; n; M; N; NE)
  • Geometrické: =NEGBINOM.DIST(1; x; p) (Excel nemá přímou funkci GEOM.DIST, používá se tato varianta negativně binomického rozdělení). Hodneota \(x\) vyjadřuje počet neúspěchů před prvním úspěchem
  • Poissonovo: =POISSON.DIST(x; lambda; NE)
PoznámkaKlíčové poznatky
  • Pravděpodobnostní distribuce je souhrn včech možných výsledků s jejich pravděpodobnostmi
  • u malého počtu možností nejčastěji tabulkou
  • u většího počtu možností grafem
  • u teoretických distribucí vzorcem a grafem
  • pro teoretické i empirické pravděpodobnosti stejné

Popisuje pravděodobnost několika úspěchů. Typickou otázkou je například: *„Jaká je pravděpodobnost, že když hodíme šesti kostkami, tak padnou dvě šestky?“*

::: {.callout-note}
## Binomická distribuce (předpoklady)
Abychom mohli mluvit o binomickém rozdělení, musí být splněno:

- Pokus končí buď **úspěchem**, nebo **neúspěchem**.

**Obecný vzorec:**
$$p(x) = \binom{n}{x} \cdot \pi^x \cdot (1-\pi)^{n-x}$$

- Máme konečný soubor o velikosti $N$.

$$P(x) = \frac{\binom{M}{x}\cdot \binom{N-M}{n-x}}{\binom{N}{n}}$$

## Poissonovo rozdělení
Vyjadřuje pravděpodobnost výskytu $k$ událostí v určitém pevném intervalu (času, plochy atd.). Například počet pacientů přicházejících na pohotovost během jedné hodiny [@wikipedia_poisson].

::: {.callout-note appearance="simple"}
## Předpoklady (Poisson)
- Události nastávají **nezávisle** na sobě.
- Průměrná četnost výskytu ($\lambda$) je **konstantní**.
- Dvě události nemohou nastat v přesně stejný okamžik.

**Obecný vzorec:**
$$P(x) = \frac{\lambda^x \cdot e^{-\lambda}}{x!}$$
:::

```{ojs}
//| echo: false
// 1. Slider
viewof lambda = Inputs.range([0.1, 20], {step: 0.1, value: 3, label: "Průměrná četnost (λ)"})

// 2. Vlastní funkce faktoriálu (bezpečná)
function myFactorial(n) {
  let res = 1;
  for (let i = 2; i <= n; i++) res *= i;
  return res;
}

// 3. Výpočet dat
poissonData = d3.range(21).map(k => ({
  k: k,
  y: (Math.pow(lambda, k) * Math.exp(-lambda)) / myFactorial(k)
}))

// 4. Graf s osou typu "band"
Plot.plot({
  height: 250,
  y: { 
    grid: true, 
    label: "P(X = k)",
    domain: [0, 0.5] 
  },
  x: { 
    label: "Počet událostí (k)",
    type: "band" // TOTO vyřeší zobrazení sloupců
  },
  marks: [
    Plot.barY(poissonData, {
      x: "k", 
      y: "y", 
      fill: "steelblue",
      tip: true
    }),
    Plot.ruleY([0])
  ]
})
```

## 💡 Jak na to v Excelu?
Pokud potřebujete tyto pravděpodobnosti spočítat v tabulkovém procesoru, použijte následující funkce. Poslední hodnotu ve funkci nastavte na `NE` (nebo `0`) pro pravděpodobnost přesné hodnoty, nebo na `ANO` (nebo `1`) pro kumulativní pravděpodobnost.

* **Binomické:** `=BINOM.DIST(x; n; p; NE)`
* **Hypergeometrické:** `=HYPGEOM.DIST(x; n; M; N; NE)`
* **Geometrické:** `=NEGBINOM.DIST(1; x; p)` *(Excel nemá přímou funkci GEOM.DIST, používá se tato varianta negativně binomického rozdělení). Hodneota $x$ vyjadřuje počet neúspěchů před prvním úspěchem*
* **Poissonovo:** `=POISSON.DIST(x; lambda; NE)`
:::

## Klíčové poznatky
- Pravděpodobnostní distribuce je souhrn včech možných výsledků s jejich pravděpodobnostmi
- u malého počtu možností nejčastěji tabulkou
- u většího počtu možností grafem
- u teoretických distribucí vzorcem a grafem
- pro teoretické i empirické pravděpodobnosti stejné
